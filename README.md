# 🎵 MusicFun

MusicFun is a modern music streaming web application where users can discover songs, browse artists and albums, and listen to track previews.

## 🚀 Tech Stack

- React
- TypeScript
- Redux Toolkit
- RTK Query
- React Router
- CSS Modules

## ✨ Features

- 🔍 Search for songs and albums
- 🎵 Listen to track previews
- ❤️ Add tracks to favorites
- 📀 Browse album information

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/hoakiin/musicfun.git
```

### Navigate to the project directory

```bash
cd musicfun
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
